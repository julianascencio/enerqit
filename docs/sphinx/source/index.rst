EnerQit
========

.. important::

   **Quantum-inspired is not quantum computing.** The supplied solvers execute
   classical algorithms on a CPU. The QAOA example simulates a quantum circuit
   on a classical computer. No quantum hardware execution or quantum advantage
   is demonstrated by this project.


Reproducible photovoltaic inverse problems and quantum-inspired optimization.
Version 0.1.0 is a research implementation validated on synthetic examples.
The code uses pvlib forward physics and keeps physical inference, binary
encoding, solver performance, and commercial evidence separate.
