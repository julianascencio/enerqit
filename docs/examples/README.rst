Example Gallery
===============

All examples run locally on deterministic synthetic data. None downloads a
plant dataset, connects to an operational platform, or uses quantum hardware.
Run an individual file from the repository root after installing the package.

The gallery covers three complementary parts of an EnerQit study:

* **Physical inference:** fixed-array orientation, tracker geometry, IV
  reconstruction and inverter response curves.
* **Optimization methods:** coupled configuration benchmarks and a small
  classical QAOA simulation with quantum-model export conventions.
* **Evidence and analysis:** daily ingestion, corrections and immutable
  study snapshots.

Each page includes the source code, generated results and downloadable Python
and notebook versions. Read the :doc:`input requirements </data_contract>` and
:doc:`method limitations </methods>` before adapting an example to real data.
